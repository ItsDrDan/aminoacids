# Peptide Party: Amino Acids & Proteins (CHEM 3B)

Interactive study game by Dr. Dan (ItsDrDan) for the CHEM 3B amino acids and proteins unit.

- **Amino Acids & R Groups**: names, 3- and 1-letter codes, side-chain classes, zwitterions and charge (pH 7.4, pH = pI, below/above pI)
- **Condense & Hydrolyze**: build peptides by removing H₂O; cut peptide bonds by adding H₂O
- **Codon Decoder**: translate mRNA with the codon chart, anticodons, mutations
- **Name That Peptide**: N- to C-terminus naming, -yl names, one-letter sequences
- **Protein Structure**: primary, secondary (α-helix, β-sheet), tertiary, quaternary
- **R-Group Interactions**: salt bridges, hydrogen bonds, disulfide bonds, hydrophobic interactions, denaturation
- **Exam Practice**: final-exam style questions from Final Boss

Side chains follow the CHEM 3B Exam #3 Reference Sheet. Single self-contained `index.html`; works on GitHub Pages and embedded in Canvas.
